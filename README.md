# superhot-wellbore
Code accompanying: Scott, S.W. (2025), "Thermo-Hydraulic Drivers of Superhot Geothermal Well Performance," Geothermics.

Description
Python framework coupling steady-state radial Darcy reservoir flow, a thermohydraulic wellbore simulator, and binary/flash power cycle analysis for superhot geothermal wells.
Requirements

Python 3.x
CoolProp
iapws
NumPy, SciPy, Matplotlib

Contents

wellbore_physics.py — Wellbore pressure and enthalpy gradient integration
reservoir.py — Radial Darcy flow model and reservoir-wellbore coupling
power_cycle.py — Binary and flash power cycle analysis
figure*.py — Scripts to reproduce all figures in the manuscript
